## Essence
Map the factors the industry competes on, then act on all four: ELIMINATE factors the industry takes for granted, REDUCE factors below standard, RAISE factors above standard, CREATE factors never offered. Real differentiation requires elimination — a value curve that only raises and creates is a cost curve.

## Interrogation set
1. List the 6–10 factors this industry competes on. Does the draft's recommendation have a visibly DIFFERENT curve, or the same curve slightly higher?
2. What does the recommendation ELIMINATE? If nothing: where does the margin for the raises come from?
3. Which factor is every competitor maximizing that this buyer's job doesn't actually need? (Overserved factor = elimination candidate.)
4. What CREATED factor changes the buyer comparison set entirely, making feature tables against incumbents irrelevant?
5. Would the eliminated/reduced factors alienate the target segment — or only the segment the strategy already conceded?
6. Draw the curve for the nearest competitor's likely RESPONSE — does the differentiation survive one imitation cycle?

## How to apply
- Force the four quadrants explicitly; empty Eliminate/Reduce quadrants are the finding.
- Weak answer smell: "premium features at affordable price"; differentiation claims listing only additions.
- Does NOT apply: cost-leadership plays or monopoly/utility contexts.

## Output contract
Revision must include the factor list, the four ERRC moves with at least one genuine elimination, and the post-imitation defensibility of the new curve.
