## Essence
TAM (everyone who could ever buy) → SAM (reachable with this product/geography/channel) → SOM (winnable given competition and capacity, in a stated timeframe). A size is credible only when top-down (analyst reports) and bottom-up (buyers × frequency × price) arrive within ~2× of each other — the divergence is where the insight lives.

## Interrogation set
1. Was the size built top-down, bottom-up, or both? If only one: rebuild the other way — where do they diverge and why?
2. What EXACTLY makes the SAM "addressable" — which filter (geography, segment, channel, willingness-to-pay) was applied, and which was conveniently skipped?
3. Is the SOM justified by named competitors' actual revenues/share, or is it "1% of a big number"?
4. Whose revenue is being counted? (Seat licenses vs usage vs services; RTD-vs-café conflation class of error.)
5. What is the size TODAY vs the projected size — and does the recommendation need the projection to be true?
6. Does the draft size the PROBLEM (spend on the pain) or the PRODUCT category? Which does the decision need?

## How to apply
- Force units: "$X market" must resolve to (# buyers) × (annual spend). If it can't, it's borrowed rhetoric.
- Weak answer smell: three analyst-report CAGRs averaged; SOM appearing only as a percentage; no timeframe on SOM.
- Does NOT apply: pure competitive-dynamics questions where size is undisputed context.

## Output contract
Revision must show both sizing directions with reconciliation, an explicit addressability filter chain TAM→SAM→SOM, and SOM anchored to named competitor benchmarks with a timeframe.
