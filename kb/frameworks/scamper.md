## Essence
Seven mechanical operators applied to an existing product/plan: Substitute, Combine, Adapt, Modify/Magnify, Put to other use, Eliminate, Reverse. Its power in review is not creativity theater — it is a completeness check on the OPTION SET before deep evaluation is trusted.

## Interrogation set
1. The draft evaluates N options. Run SCAMPER on the core offering — which operators produce a credible option the draft never considered?
2. SUBSTITUTE: what if the costliest component (model, channel, human step) were swapped for the cheap version?
3. COMBINE: what adjacent capability, bundled, changes the value proposition entirely?
4. ELIMINATE: what does the "obvious" version include that the target job doesn't need — and what does removing it do to price and speed?
5. PUT TO OTHER USE: which existing asset (data, traffic, workflow) serves a different buyer with near-zero marginal cost?
6. REVERSE: flip the model — who pays, who's the product, what's free? Does any reversal beat the draft's option?

## How to apply
- Two minutes per operator; keep only options that survive a plausibility sniff — the goal is a wider funnel, not a longer list.
- Weak answer smell: "we considered several options" with no evidence of generation discipline; option B and C that are strawmen of option A.
- Does NOT apply: pure diagnostic/landscape asks with no design freedom.

## Output contract
Revision must show the considered option set (including discarded options with one-line reasons) before the recommendation, proving the winner beat real alternatives, not strawmen.
